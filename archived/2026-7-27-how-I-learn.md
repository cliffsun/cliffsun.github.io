Learning how to learn is one of the best skills I've ever picked up. Productively learning. As a person who constantly

- Constantly explores
- Always curious
- learning how to learn
- #1: Figuring out what's important (relevant equations, code, etc.)
- #2: Disciplined curiosity (learning what's necessary, saving the rest for later)
- #3: When to not learn (you can't always learn, it takes time and energy)
- #4: Progress is different each day, but push to make some progress. (writing a sentence or finishing a paper, progress looks different. Some days are bad. Learning is a continuous procedure, so as long as progress is made, then you can be satisfied. )
